# 📖 Словесник — ИИ-помощник по русскому языку и литературе

Веб-приложение для студентов вузов: объясняет темы, генерирует тесты и практические задания, проверяет ответы с помощью искусственного интеллекта (Google Gemini).

## Возможности

| Раздел | Что умеет |
|---|---|
| 📘 Русский язык | 10 разделов, 60+ тем; объяснение теории; генерация тестов (3–15 вопросов, 3 уровня сложности); практические задания с проверкой ответов ИИ |
| 📚 Литература | от фольклора до XX века и теории литературы; краткое содержание, анализ, герои, план сочинения, вопросы к семинару, об авторе; тесты; портреты авторов (Wikipedia); ИИ-иллюстрации (Pollinations) |
| 💬 Чат-помощник | отдельные чаты по русскому языку и по литературе, помнит контекст беседы |

## Технологии

- Python 3.10+, [Streamlit](https://streamlit.io)
- Google Gemini API (бесплатный тариф), автопереключение между моделями при перегрузке
- Wikipedia API — портреты писателей
- Pollinations.ai — генерация иллюстраций

## Структура

```
app.py        — интерфейс (страницы, тесты, чат)
llm.py        — запросы к Gemini, повтор при ошибках
prompts.py    — системные промпты и шаблоны заданий
topics.py     — каталог тем и произведений
```

## Запуск локально

```bash
pip install -r requirements.txt
mkdir -p .streamlit
echo 'GEMINI_API_KEY = "ваш_ключ"' > .streamlit/secrets.toml
streamlit run app.py
```

Ключ бесплатно выдаётся на https://aistudio.google.com → Get API key.

## Публикация (Streamlit Community Cloud)

1. Зайти на https://share.streamlit.io через GitHub.
2. **Create app** → выбрать этот репозиторий, ветка `main`, файл `app.py`.
3. **Advanced settings → Secrets**: вставить `GEMINI_API_KEY = "ваш_ключ"`.
4. **Deploy** — через 1–2 минуты приложение доступно по ссылке.

## Ограничения

- ИИ может ошибаться: сгенерированные задания стоит выборочно проверять преподавателю.
- Бесплатные лимиты Gemini и Pollinations ограничивают число запросов в минуту.
